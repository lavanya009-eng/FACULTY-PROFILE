Learning Outcomes

After studying this unit, students should be able to:

  • Explain sample complexity, computational complexity and mistake bounds.
  • Define true error, training error and probably approximately correct (PAC) learning.
  • Use finite-hypothesis-space bounds to estimate a sufficient number of training examples.
  • Explain shattering and calculate the VC dimension for simple hypothesis spaces.
  • Describe the mistake-bound ideas behind FIND-S, HALVING and Weighted-Majority.
  • Apply k-nearest neighbour to classification and regression problems.
  • Explain distance weighting, locally weighted regression and radial basis functions.
  • Describe case-based reasoning and distinguish lazy learning from eager learning.

A. Computational Learning Theory

1. Introduction

Computational Learning Theory studies the fundamental limits and requirements of learning. Instead of asking only how a particular algorithm works, it asks whether a class of learning problems can be learned efficiently, how much data is required, and how many prediction mistakes may occur before learning succeeds.

The uploaded slides raise four central questions: which learning problems are inherently easy or difficult; how many examples are sufficient; how learning changes when the learner can ask queries instead of receiving random examples; and how many mistakes occur before the target function is learned.

MeasureMeaningCentral question
Sample complexityNumber of training examples required.How much data is needed?
Computational complexityComputational effort or running time required.How much processing is needed?
Mistake boundMaximum number of prediction errors before convergence.How many wrong predictions can occur?
Illustration – student performance prediction

Suppose a model predicts whether a student will pass using attendance, internal marks and assignment completion. Sample complexity asks how many labelled student records are needed. Computational complexity asks how much time the algorithm needs to learn. Mistake bound asks how many online predictions may be wrong before the learner identifies the target concept under the model's assumptions.

2. The learning problem setting

Let \(X\) be the set of all possible instances. A target concept \(c\) assigns a correct label to each instance. For binary classification, \(c:X\rightarrow\{0,1\}\), where 1 denotes a positive example and 0 denotes a negative example.

Examples are drawn according to an instance distribution \(D\). The learner receives a training set \(S\) containing pairs \((x,c(x))\), and searches a hypothesis space \(H\) for a hypothesis \(h\) that predicts labels for unseen instances.

\[S=\{(x_1,c(x_1)),(x_2,c(x_2)),\ldots,(x_m,c(x_m))\}\]

The distribution \(D\) is generally unknown. The learner's performance is judged on new examples drawn from the same distribution, not merely on the examples it has already seen.

3. Error of a hypothesis

True error is the probability that hypothesis \(h\) disagrees with the target concept on a randomly drawn instance.

\[\operatorname{error}_{D}(h)=\Pr_{x\sim D}[h(x)\ne c(x)]\]

Training error is the fraction of the observed training examples that \(h\) classifies incorrectly.

\[\operatorname{error}_{S}(h)=\frac{1}{m}\sum_{i=1}^{m}\mathbf{1}[h(x_i)\ne c(x_i)]\]
Important distinction: Training error is measured on known examples. True error concerns future examples from the underlying distribution. A hypothesis can have zero training error and still make errors on unseen data.
Worked illustration

A classifier is tested on 100 labelled training records and misclassifies 5.

  • Training error = \(5/100=0.05=5\%\).
  • This does not prove that its true error is 5%; a separate unseen sample or a theoretical bound is needed to reason about generalisation.

4. Probably Approximately Correct (PAC) Learning

PAC learning formalises the idea that a learner should, with high probability, produce a hypothesis whose true error is small. “Probably” refers to confidence; “approximately correct” refers to an acceptable error level.

A concept class is PAC-learnable when, for chosen accuracy parameter \(\epsilon\) and confidence parameter \(\delta\), the learner outputs a hypothesis with true error at most \(\epsilon\), with probability at least \(1-\delta\), using resources polynomially bounded in the relevant problem parameters.

\[\Pr\big[\operatorname{error}_{D}(h)\le \epsilon\big]\ge 1-\delta\]
ParameterMeaningInterpretation
\(\epsilon\)Error toleranceSmaller \(\epsilon\) means higher desired accuracy.
\(\delta\)Failure probabilitySmaller \(\delta\) means higher confidence.
\(1-\delta\)ConfidenceProbability that the learned hypothesis meets the error requirement.
Example

If \(\epsilon=0.05\) and \(\delta=0.01\), the PAC goal is to obtain a hypothesis whose true error is at most 5%, with probability at least 99%.

5. Sample Complexity for Finite Hypothesis Spaces

When \(H\) is finite, the number of hypotheses is \(|H|\). A learner may select a hypothesis that correctly classifies all observed training examples. The set of all such consistent hypotheses is called the version space.

\[VS_{H,S}=\{h\in H:\forall (x,c(x))\in S,\ h(x)=c(x)\}\]

A version space is \(\epsilon\)-exhausted when every remaining hypothesis has true error less than \(\epsilon\). The finite-space bound in the supplied slides is:

\[\Pr(\text{version space is not }\epsilon\text{-exhausted})\le |H|e^{-\epsilon m}\]

To make this failure probability no greater than \(\delta\), require:

\[|H|e^{-\epsilon m}\le\delta\]
\[\boxed{m\ge \frac{1}{\epsilon}\left(\ln |H|+\ln\frac{1}{\delta}\right)}\]

This gives a sufficient number of examples for any consistent learner under the assumptions of the bound: independent random examples, a finite hypothesis space, and a realizable/noiseless target represented in the hypothesis space.

Worked numerical problem – finite hypothesis space

Suppose \(|H|=100\), desired error \(\epsilon=0.10\), and failure probability \(\delta=0.05\).

  1. Use \(m\ge \frac{1}{\epsilon}(\ln|H|+\ln(1/\delta))\).
  2. \(\ln 100=4.6052\); \(\ln 20=2.9957\).
  3. \(m\ge 10(4.6052+2.9957)=76.009\).
  4. Round up: at least 77 training examples.

This is a sufficient theoretical bound, not a guarantee that every dataset of 77 examples will be representative.

6. Agnostic learning and inconsistent hypotheses

The earlier finite-space bound assumes a consistent hypothesis with zero training error. In practical or noisy data, no hypothesis may classify every training example correctly. The learner may instead choose \(h_{\text{best}}\), the hypothesis with the lowest training error in \(H\).

The supplied slides use the Hoeffding bound and a union bound over the finite hypothesis space to obtain:

\[\Pr\left[\exists h\in H:\operatorname{error}_{D}(h)>\operatorname{error}_{S}(h)+\epsilon\right]\le |H|e^{-2m\epsilon^2}\]

Solving for \(m\) gives the sufficient bound:

\[\boxed{m\ge \frac{1}{2\epsilon^2}\left(\ln|H|+\ln\frac{1}{\delta}\right)}\]

Unlike the consistent case, the sample requirement grows with \(1/\epsilon^2\). This is a bound on how far true error may exceed observed training error, simultaneously for hypotheses in the finite space.

7. Conjunctions of Boolean literals

For \(n\) Boolean variables, each variable has three possible roles in a conjunction: include it positively, include its negation, or omit it. Therefore:

\[|H|=3^n\]

Substituting this into the finite-space consistent learner bound:

\[m\ge \frac{1}{\epsilon}\left(n\ln 3+\ln\frac{1}{\delta}\right)\]
Illustration

For \(n=4\), the number of conjunction hypotheses is \(3^4=81\). The bound can be calculated by substituting \(|H|=81\), or directly using \(4\ln3\), along with the chosen \(\epsilon\) and \(\delta\).

8. PAC-learnability of other concept classes

The slides distinguish sample complexity from computational complexity. A concept class can have a polynomial sample requirement yet still be difficult to learn in polynomial time using a particular representation or learner.

  • Unbiased learners: the slides discuss the unbiased concept class, where the learner's hypothesis space must itself be unbiased. This can make the finite-space sample bound unsuitable or very large.
  • k-term DNF: the supplied slides state that k-term DNF has polynomial sample complexity but is not polynomial-time learnable by a learner using \(H=C\), under the discussed setting.
  • k-CNF: the slides state that k-CNF is more expressive than k-term DNF and has polynomial sample and time complexity in the presented result; this gives an efficient learner for k-term DNF using \(H=\) k-CNF.
Scope note: The uploaded slides give these results mainly as summary statements. Detailed proofs and formal reductions are not developed in the supplied material, so they are not reconstructed here.

9. Sample Complexity for Infinite Hypothesis Spaces: VC Dimension

For an infinite hypothesis space, counting \(|H|\) is not useful. The Vapnik–Chervonenkis (VC) dimension measures the expressive capacity of a hypothesis space by asking how many instances it can label in every possible way.

Shattering

A hypothesis space \(H\) shatters a finite set \(S\) if every possible binary labelling (dichotomy) of \(S\) can be produced by some hypothesis in \(H\). A set of \(d\) instances has \(2^d\) possible binary labelings.

\[\text{Number of dichotomies on }d\text{ points}=2^d\]

Definition of VC dimension

The VC dimension of \(H\), written \(VC(H)\), is the size of the largest set of instances that can be shattered by \(H\). If arbitrarily large finite sets can be shattered, the VC dimension is infinite.

\[VC(H)=\max\{|S|:H\text{ shatters }S\}\]

Example 1 – intervals on the real line

Let \(X=\mathbb{R}\), and let \(H\) contain all intervals \(a<x<b\). Two ordered points can be labelled in all four possible ways by selecting a suitable interval. However, three ordered points cannot be shattered: an interval cannot label the first and third points positive while the middle point is negative. Therefore:

\[\boxed{VC(H)=2}\]

Example 2 – linear decision surfaces

The supplied slides state that a perceptron with \(r\) inputs (linear decision surfaces in an \(r\)-dimensional space) has:

\[VC(H)=r+1\]

Thus, for a two-input perceptron, the VC dimension is 3.

VC dimension and sample complexity

The slides emphasise that the VC dimension replaces the simple count \(|H|\) as a measure of complexity for many infinite hypothesis spaces. A common form of the realizable PAC sample bound, for finite VC dimension \(d\), is of order:

\[m=O\left(\frac{1}{\epsilon}\left(d\log\frac{1}{\epsilon}+\log\frac{1}{\delta}\right)\right)\]

This expression conveys the key relationship: more expressive hypothesis spaces (larger VC dimension) generally require more examples to achieve the same accuracy and confidence.

VC dimension for neural networks

The uploaded slides include a section on VC dimension for neural networks, but the slide content supplied is primarily a heading/illustration and does not provide a complete derivation or a specific numerical formula. The key idea is that network capacity depends on its architecture and number of adjustable parameters; a larger capacity can represent more complex decision boundaries and may require more training data.

10. The Mistake-Bound Model of Learning

In the mistake-bound model, learning is evaluated by the total number of incorrect predictions made before the learner converges to the correct target concept. This differs from PAC analysis, which focuses on the number of random training examples needed to achieve a desired error and confidence.

10.1 FIND-S mistake bound

FIND-S begins with the most specific hypothesis and generalises it when it receives positive examples. Under the assumptions stated in the slides (noise-free data and a target concept representable in the hypothesis space), the hypothesis is always at least as specific as the target concept. The mistakes to count are therefore positive examples initially predicted as negative.

\[\boxed{\text{Mistake bound for FIND-S}\le n+1}\]

Here \(n\) is the number of literals/attributes in the representation used in the slides. In the worst case, each mistake removes only one literal before the most general target is reached.

10.2 HALVING algorithm

HALVING maintains the current version space and predicts by majority vote among its hypotheses. After a mistake, at least half of the remaining hypotheses are eliminated. Therefore, for finite \(H\), the number of mistakes is logarithmically bounded by the initial number of hypotheses.

\[\boxed{\text{Mistakes}\le \log_2|H|}\]
Worked illustration

If the initial version space contains 64 hypotheses, then:

\(\log_2 64=6\). Thus the HALVING bound is 6 mistakes. Each mistake reduces the version space by at least half: 64 → 32 → 16 → 8 → 4 → 2 → 1.

10.3 Optimal mistake bounds and Weighted-Majority

The uploaded slide deck lists “Optimal Mistake Bounds” and “Weighted-Majority Algorithm” as final topics, but provides only headings without enough explanatory text or equations to reproduce the detailed derivation. At a high level, Weighted-Majority combines predictions from multiple experts or prediction rules by assigning weights and giving more influence to better-performing predictors. The detailed update rule and its formal bound are not specified in the supplied slides.

B. Instance-Based Learning

11. Introduction

Instance-based learning stores training examples instead of constructing one global model during training. When a new query instance arrives, the learner retrieves similar stored examples and uses them to predict the target value.

These methods can build a different local approximation for each query. This is useful when a complex target function can be described by simpler local regions. The main disadvantages are potentially high prediction cost and the possibility that irrelevant attributes distort similarity calculations.

12. k-Nearest Neighbour (k-NN) Learning

In k-NN, instances are represented as points in an \(n\)-dimensional feature space. The algorithm finds the \(k\) stored training instances closest to the query point \(x_q\). For numerical features, the slides define distance using Euclidean distance.

\[d(x_i,x_j)=\sqrt{\sum_{r=1}^{n}(a_r(x_i)-a_r(x_j))^2}\]

Algorithm

  1. Store every labelled training example.
  2. For a query \(x_q\), calculate its distance from the training examples.
  3. Select the \(k\) examples with the smallest distances.
  4. For classification, return the majority class among those neighbours.
  5. For regression, return the mean target value of the \(k\) neighbours.

For discrete-valued targets:

\[\hat f(x_q)=\arg\max_{v\in V}\sum_{i=1}^{k}\mathbf{1}[v=f(x_i)]\]

For real-valued targets:

\[\hat f(x_q)=\frac{1}{k}\sum_{i=1}^{k}f(x_i)\]

Worked numerical example – classification

Suppose a query student's feature vector is \((\text{attendance},\text{internal mark})=(80,70)\). The following training records are available:

StudentAttendanceInternal markClassEuclidean distance from (80,70)
A7868Pass\(\sqrt{2^2+2^2}=2.83\)
B8572Pass\(\sqrt{5^2+2^2}=5.39\)
C7565Fail\(\sqrt{5^2+5^2}=7.07\)
D7060Fail\(\sqrt{10^2+10^2}=14.14\)
E8875Pass\(\sqrt{8^2+5^2}=9.43\)

For \(k=3\), the three nearest neighbours are A (Pass), B (Pass) and C (Fail). Majority vote is Pass (2 out of 3). Therefore the predicted class is Pass.

Effect of k: A small \(k\) can be sensitive to noise; a larger \(k\) smooths the decision but may blur local structure. An odd \(k\) is often chosen for two-class classification to reduce ties.

Decision surface and Voronoi diagram

The slide deck's Figure 8.1 illustrates that 1-NN assigns each query to the class of its closest training example. The regions closest to each stored point form a Voronoi partition. The same figure shows that a query can be classified positive by 1-NN but negative by 5-NN, because the larger neighbourhood has a different majority.

12.1 k-NN for regression

For a real-valued target, k-NN predicts the average of the target values of the nearest neighbours. For example, if the three nearest houses have prices ₹40 lakh, ₹45 lakh and ₹50 lakh, the predicted price is:

\[\hat f(x_q)=\frac{40+45+50}{3}=45\text{ lakh}\]

13. Distance-Weighted Nearest Neighbour

Ordinary k-NN gives every selected neighbour an equal vote. Distance-weighted k-NN gives more influence to closer neighbours. The supplied slides use inverse-square distance weighting:

\[w_i=\frac{1}{d(x_q,x_i)^2}\]

For classification, the weighted vote for each class is summed. For regression, the weighted average is used:

\[\hat f(x_q)=\frac{\sum_{i=1}^{k}w_i f(x_i)}{\sum_{i=1}^{k}w_i}\]
Worked example – weighted regression

Two nearest examples have target values 10 and 20, at distances 1 and 2.

  • \(w_1=1/1^2=1\)
  • \(w_2=1/2^2=0.25\)

\(\hat f(x_q)=\frac{1(10)+0.25(20)}{1+0.25}=\frac{15}{1.25}=12\).

The nearer example has greater influence, so the prediction (12) is closer to 10 than to 20.

If the query exactly matches a stored training example, its distance is zero. The slide notes that the prediction should be set to that example's target value; if multiple exact matches exist, use their majority class for classification.

Local and global methods

  • Local method: uses only the nearest training examples.
  • Global method: considers all training examples. The slides identify the global distance-weighted form as Shepard's method.

14. Remarks and practical issues in k-NN

Curse of dimensionality and irrelevant attributes

Distance is often calculated using all attributes. If only a few attributes are relevant and many are irrelevant, the irrelevant dimensions can dominate the distance and make genuinely similar examples appear far apart. The slides refer to this issue as the curse of dimensionality.

Illustration

Suppose student success depends mainly on attendance and internal marks, but the dataset also contains 18 unrelated attributes. A distance calculation over all 20 attributes may be misleading. Feature selection or attribute weighting can improve the similarity measure.

Efficient memory indexing – kd-tree

Because k-NN delays much of its computation until a query arrives, prediction can be expensive. The slides introduce the kd-tree: training instances are stored at leaves, nearby instances are organised in nearby regions, and internal nodes test selected attributes to direct a query toward a relevant leaf.

15. Locally Weighted Regression (LWR)

Locally weighted regression constructs an explicit approximation to a real-valued target function near the query point \(x_q\). It is:

  • Local because it focuses on data near the query.
  • Weighted because nearby examples receive greater weight.
  • Regression because it approximates a real-valued function.

Unlike a single global regression model, LWR may fit a new local model for each query instance. The supplied slides introduce a local linear approximation:

\[\hat f(x)=w_0+w_1a_1(x)+\cdots+w_na_n(x)\]

In ordinary global linear regression, coefficients are selected by minimising the total squared error:

\[E=\frac{1}{2}\sum_{x\in D}(f(x)-\hat f(x))^2\]

For local regression, the error criterion is modified so that nearby examples matter more. The slides present three alternatives:

  1. Minimise squared error over only the \(k\) nearest neighbours.
  2. Use all training examples, but weight each squared error by a decreasing function \(K\) of distance from the query.
  3. Combine the nearest-neighbour restriction with distance weighting.
\[E_2(x_q)=\frac{1}{2}\sum_{x\in D}(f(x)-\hat f(x))^2K(d(x_q,x))\]

Here \(K(d)\) is a kernel/weight function that decreases as distance increases. The resulting local model is fitted for the current query and used to calculate \(\hat f(x_q)\).

Worked conceptual example

Suppose we want to predict house price near a particular locality. A single straight line fitted across an entire city may not describe every locality well. LWR fits a local line using nearby houses, giving close properties greater influence. A different query locality can produce a different fitted line.

Remarks

The slides state that local target functions are commonly approximated using constant, linear or quadratic functions. More complex functions are often avoided because fitting them separately for every query is expensive, while simple models may fit a sufficiently small local region well.

16. Radial Basis Functions (RBF)

Radial basis function learning is related to distance-weighted regression and neural networks. An RBF unit responds according to the distance between the input and a centre. A commonly used Gaussian radial basis function is:

\[\phi_j(x)=\exp\left(-\frac{\|x-\mu_j\|^2}{2\sigma_j^2}\right)\]

Here \(\mu_j\) is the centre of unit \(j\), and \(\sigma_j\) controls its width. The response is largest at the centre and decreases as the input moves away.

A network combines several such local responses, typically using a weighted sum:

\[\hat f(x)=w_0+\sum_{j=1}^{M}w_j\phi_j(x)\]

Role of width: a small \(\sigma\) gives a narrow response around the centre; a large \(\sigma\) gives a broader response. The uploaded slide deck introduces RBFs but does not provide a complete derivation of centre/width selection or training; the Gaussian expression above is a standard explanatory form to make the slide topic understandable.

17. Case-Based Reasoning (CBR)

Case-based reasoning uses previously solved cases to help solve a new problem. It shares two properties with k-NN and locally weighted regression: it delays generalisation until a query arrives and retrieves cases similar to the new problem. Unlike standard nearest-neighbour methods, cases need not be represented as numerical points in Euclidean space; they may use rich symbolic descriptions.

Applications mentioned in the supplied slides include conceptual design of mechanical devices, reasoning about legal cases using previous rulings, and planning/scheduling by reusing parts of earlier solutions.

CADET example from the slides

CADET supports conceptual design of simple mechanical devices such as water faucets. Its library contains approximately 75 earlier designs and design fragments. A stored case such as a T-junction pipe is represented using its structure and qualitative function. For example, the functional description can state that output water flow \(Q_3\) increases when input flow \(Q_1\) increases.

For a new design problem, CADET searches for stored cases whose functional descriptions match the requested function. It may return an exact match or identify a case that matches part of the desired functional specification. The slides note that CADET has limited ability to combine and adapt multiple retrieved cases, and relies substantially on the user for adaptation.

CBR cycle – classroom summary: retrieve a similar case → reuse its solution → revise/adapt it for the new problem → retain the new experience as a case. The uploaded slides describe retrieval and adaptation in the CADET example; this four-stage wording is a general teaching summary of the CBR process.

18. Lazy Learning and Eager Learning

The final slides compare lazy and eager learning in terms of computation and inductive bias.

Lazy learningEager learning
Stores training examples and delays generalisation until a query arrives.Builds a general model during training.
Usually less computation during training.Usually more computation during training.
Usually more computation at prediction time.Usually less computation at prediction time.
Can use the query point to choose a local approximation.Commits to a global approximation before seeing future queries.
Examples: k-NN, locally weighted regression.Examples: decision trees and many fitted global models.

The slides emphasise that lazy methods can implicitly represent a target function using many local approximations. Eager methods generally commit to one global approximation, although some eager models, such as RBF networks, can combine multiple local approximations.

Analogy

A lazy learner is like a librarian who waits for a specific question, then searches for the most relevant stored examples. An eager learner is like a teacher who studies all examples in advance and prepares a general rule before the question is asked.
