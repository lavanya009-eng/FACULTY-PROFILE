UNIT II – Overview

This unit develops three connected ideas: constructing decision trees from examples, estimating how well a learned hypothesis will perform on unseen data, and using probability to reason about hypotheses and classifications.

Learning outcomes
After completing this unit, students should be able to:
  • Represent classification knowledge using decision trees and convert paths into rules.
  • Calculate entropy and information gain and trace the ID3 algorithm.
  • Explain hypothesis-space search, inductive bias, Occam’s razor and overfitting.
  • Distinguish sample error from true error and calculate approximate confidence intervals.
  • Explain sampling distributions, bias, variance and the Central Limit Theorem.
  • Apply Bayes’ theorem, calculate posterior probabilities and distinguish MAP from maximum likelihood.
  • Explain MDL, Bayes optimal classification, Gibbs sampling and Naïve Bayes.
  • Describe conditional independence and the basic purpose of Bayesian belief networks.

Suggested teaching time: 12–15 hours. Prerequisites: Unit I concepts, basic logarithms, probability and algebra.

Textbook basis: Tom M. Mitchell, Machine Learning, Chapters 3, 5 and 6. The order below follows the Unit II slide sequence.

A. DECISION TREE LEARNING

1. Introduction

Decision tree learning is a method for approximating discrete-valued target functions. The learned function is represented as a tree. A decision tree can also be rewritten as a set of IF–THEN rules, which often makes the learned knowledge easier for a person to understand.

Decision trees are used in classification tasks such as medical case assessment, credit-risk analysis and equipment-fault diagnosis. A tree asks a sequence of attribute questions and follows the branch corresponding to each answer until it reaches a leaf containing a predicted class.

Healthcare example
A simplified educational decision tree might ask whether a patient has a particular symptom, then examine a laboratory result, and finally output a category used in a teaching dataset. A real diagnosis must use validated clinical processes; this illustration only explains the structure of a classifier.

2. Decision Tree Representation

  • Root node: the first attribute test.
  • Internal node: a test on an attribute.
  • Branch: one possible value of the tested attribute.
  • Leaf: the predicted target class.

To classify an instance, start at the root, evaluate the attribute test, follow the matching branch, and repeat until a leaf is reached.

Example tree – PlayTennis idea
Outlook?
↙ Sunny    ↓ Overcast    ↘ Rain
Sunny → test Humidity → High: No; Normal: Yes
Overcast → Yes
Rain → test Wind → Strong: No; Weak: Yes

Each root-to-leaf path is a conjunction of tests. The whole tree is a disjunction (OR) of the paths that lead to a positive leaf. Thus a decision tree can represent concepts that require several alternative combinations of conditions.

3. Appropriate Problems for Decision Tree Learning

According to the slides, decision trees are particularly appropriate when:

  1. Instances are represented by attribute-value pairs.
  2. The target function has discrete output values, such as Yes/No.
  3. Disjunctive descriptions may be required.
  4. Training data may contain errors.
  5. Some attribute values may be missing.

Examples include medical-patient classification, equipment malfunction diagnosis and loan-default classification. These are classification problems because the target is one of a finite set of categories.

4. Entropy – Measuring Impurity

ID3 selects the attribute that is most useful for separating training examples according to their target class. To define this usefulness, we first measure the impurity of a set using entropy.

\[Entropy(S)=-p_{+}\log_2 p_{+}-p_{-}\log_2 p_{-}\]

Here \(p_+\) is the fraction of positive examples and \(p_-\) is the fraction of negative examples. By convention, \(0\log_2 0=0\).

Numerical example 1 – Entropy of [9+, 5−]

Total examples = 14. Therefore \(p_+=9/14=0.6429\) and \(p_-=5/14=0.3571\).

\[H(S)=-\frac{9}{14}\log_2\frac{9}{14}-\frac{5}{14}\log_2\frac{5}{14}\]
\[H(S)\approx -(0.6429)(-0.6374)-(0.3571)(-1.4854)\]
Answer: \(H(S)\approx0.940\) bits. The set is not pure because it contains both positive and negative examples.

For a target with \(c\) possible classes, entropy is:

\[Entropy(S)=-\sum_{i=1}^{c}p_i\log_2 p_i\]

5. Information Gain

Information gain measures the expected reduction in entropy when examples are partitioned according to an attribute \(A\).

\[Gain(S,A)=Entropy(S)-\sum_{v\in Values(A)}\frac{|S_v|}{|S|}Entropy(S_v)\]

\(S_v\) is the subset of examples for which attribute \(A\) has value \(v\). The weighted sum is the expected entropy after splitting.

Numerical example 2 – Information gain for Wind

Start with \(S=[9+,5-]\), so \(Entropy(S)=0.940\). There are 14 examples:

6. ID3 Algorithm and PlayTennis Example

ID3 (Iterative Dichotomiser 3) chooses the attribute with the highest information gain at each decision node.

Algorithm steps

  1. Create a node for the current set of examples.
  2. If all examples have the same class, make the node a leaf with that class.
  3. If no attributes remain, make a leaf with the majority class.
  4. Calculate information gain for every available attribute.
  5. Select the attribute with the highest gain.
  6. Create one branch for each value of that attribute and recursively apply the procedure to each subset.

PlayTennis dataset

The standard dataset contains 14 Saturday-morning examples. The target is PlayTennis (Yes/No), and the candidate attributes are Outlook, Temperature, Humidity and Wind.

7. Hypothesis-Space Search in Decision Tree Learning

ID3 searches the space of possible decision trees. It begins with a simple tree and progressively adds tests, using information gain as a heuristic. This is a greedy hill-climbing search from simple to more complex hypotheses.

  • The hypothesis space consists of possible decision trees.
  • With the available attributes, decision trees can represent every finite discrete-valued function over those attributes.
  • ID3 maintains one current hypothesis rather than all consistent hypotheses.
  • In its basic form, ID3 does not backtrack after selecting an attribute at a node.
  • It uses all examples at each node to make a statistical choice, which can make it less sensitive to individual noisy examples.

8. Inductive Bias in Decision Tree Learning

Usually, many decision trees can fit the same training examples. The inductive bias describes why the algorithm prefers one consistent tree over another.

The approximate bias of ID3 is:

  1. Prefer shorter trees over longer trees.
  2. Prefer trees that place high-information-gain attributes near the root.

ID3 is a greedy approximation to a search for a short tree. It uses a heuristic rather than enumerating all trees.

Restriction bias versus preference bias

Occam’s Razor – Why prefer short hypotheses?

Occam’s Razor recommends preferring the simplest hypothesis that fits the data. A very large tree can memorize accidental details in a small training set. A shorter tree is often less likely to fit the training data merely by coincidence and may generalize better. Simplicity is a useful preference, not a guarantee of correctness.

9. Issues in Decision Tree Learning

A. Overfitting

Overfitting occurs when a tree captures noise or accidental details in the training examples. It may achieve very high training accuracy but perform poorly on unseen examples. The slides identify small training sets and noisy data as common causes.

B. Reduced-error pruning

Use a separate validation set. Consider replacing a subtree with a leaf labelled by the majority class at that node. Keep the replacement if validation performance does not become worse (or improves). This reduces unnecessary branches.

C. Rule post-pruning

Convert the decision tree into rules, then consider removing conditions from each rule. Retain a simplified rule when its estimated performance is at least as good on validation data. The pruned rules may be easier to understand.

D. Other issues listed in the slides

  • Incorporating continuous-valued attributes by choosing suitable threshold tests.
  • Alternative attribute-selection measures.
  • Handling missing attribute values.
  • Handling attributes with different measurement or acquisition costs.

B. EVALUATING HYPOTHESES

10. Motivation

Evaluating a learned hypothesis helps us decide whether it is useful and is also part of many learning algorithms. When data is limited, two difficulties arise:

  • Bias in the estimate: the evaluation procedure systematically gives an estimate that differs from future performance. Testing on examples independent of training helps avoid this.
  • Variance in the estimate: measured accuracy changes depending on which random test examples happen to be selected. Small test sets usually produce greater variability.

11. Sample Error and True Error

The sample error of hypothesis \(h\) over a sample \(S\) is the fraction of examples it misclassifies:

\[\widehat{error}_S(h)=\frac{\text{number of misclassified examples in }S}{|S|}\]

The true error is the probability that \(h\) misclassifies a randomly drawn instance from the underlying distribution \(D\):

\[error_D(h)=P_{x\sim D}[h(x)\ne f(x)]\]

Numerical example

If a hypothesis misclassifies 7 out of 33 test examples:

\[\widehat{error}_S(h)=\frac{7}{33}=0.2121\approx21.21\%\]

This is the observed sample error. It estimates, but is not necessarily equal to, the true future error.

12. Basics of Sampling Theory

Suppose we repeatedly draw independent random samples of size \(n\) from a population. The measured sample error changes from sample to sample. Therefore sample error is a random variable.

Binomial distribution

For a fixed hypothesis, each independent test example is either classified correctly or incorrectly. If the true error probability is \(p\), the number of errors \(R\) in \(n\) examples follows a binomial distribution:

\[P(R=r)=\binom nr p^r(1-p)^{n-r}\]

For the sample error \(\hat p=R/n\):

\[E[\hat p]=p,\qquad Var(\hat p)=\frac{p(1-p)}{n}\]
\[SD(\hat p)=\sqrt{\frac{p(1-p)}{n}}\]

The sample error is an estimator of the true error. An estimator is unbiased when its expected value equals the parameter being estimated. Lower variance is desirable because repeated estimates fluctuate less.

13. Confidence Intervals

A confidence interval gives a range of plausible values for an unknown parameter using a stated confidence procedure. For a discrete-valued hypothesis, the slides use an approximate normal interval for the true error:

\[\hat p\ \pm\ z_{\alpha/2}\sqrt{\frac{\hat p(1-\hat p)}{n}}\]

For an approximate 95% two-sided interval, \(z_{\alpha/2}\approx1.96\).

Numerical example – n = 40 and r = 12

  1. Sample error: \(\hat p=12/40=0.30\).
  2. Standard error estimate: \(\sqrt{0.30(0.70)/40}=\sqrt{0.00525}\approx0.0725\).
  3. Margin: \(1.96(0.0725)\approx0.142\).
\[95\%~CI\approx0.30\pm0.142=[0.158,0.442]\]

Rounded to two decimal places, the interval is approximately 0.16 to 0.44. In repeated use of this procedure under its assumptions, about 95% of such intervals would contain the true error. It does not mean there is a 95% probability that this fixed parameter lies in this already calculated interval.

Assumptions and limitations
The approximation is intended for discrete-valued hypotheses, randomly drawn independent examples from the same distribution as future cases, and test data independent of the hypothesis. The slides note that the normal approximation is generally more reliable for sufficiently large samples (rule of thumb \(n\ge30\)) and when the estimated error is not too close to 0 or 1. For small samples or extreme proportions, use a more suitable interval method.

14. Sampling Theory – Central Limit Theorem

The Central Limit Theorem says that, under suitable conditions, the distribution of a sample mean becomes approximately normal as sample size grows, even when the original observations are not normally distributed. This is why a normal approximation can be used for many confidence intervals when the sample is sufficiently large.

15. One-sided and Two-sided Bounds

A two-sided interval provides both a lower and an upper bound. A one-sided interval gives only one bound, for example an upper bound on the true error. Under the normal approximation, a two-sided 95% interval corresponds to a one-sided upper bound at 97.5% confidence when using the same upper endpoint.

Using the previous example, the upper endpoint is approximately \(0.30+0.14=0.44\). Thus the slide’s one-sided interpretation gives an approximate 97.5% upper confidence bound of 0.44, under the same assumptions.

16. Difference in Error of Two Hypotheses

Suppose \(h_1\) and \(h_2\) are tested on independent samples of sizes \(n_1,n_2\), with observed errors \(\hat p_1,\hat p_2\). The estimated difference is:

\[\hat d=\hat p_1-\hat p_2\]

For sufficiently large independent samples, an approximate standard error is:

\[SE(\hat d)=\sqrt{\frac{\hat p_1(1-\hat p_1)}{n_1}+\frac{\hat p_2(1-\hat p_2)}{n_2}}\]
\[\hat d\pm z_{\alpha/2}SE(\hat d)\]

Numerical example

Suppose \(n_1=n_2=100\), \(\hat p_1=0.30\) and \(\hat p_2=0.20\).

\[\hat d=0.30-0.20=0.10\]
\[SE=\sqrt{\frac{0.3(0.7)}{100}+\frac{0.2(0.8)}{100}}\approx0.0608\]
\[95\%~CI=0.10\pm1.96(0.0608)\approx[-0.019,0.219]\]

Because this approximate interval includes zero, the observed 0.10 difference alone is not enough to establish a difference at the 95% two-sided confidence level.

The preceding formula assumes independent test samples. If two hypotheses are evaluated on the same examples, their errors are paired and the dependence must be considered; do not automatically use the independent-sample formula.

17. Comparing Learning Algorithms

Sometimes the question is not which of two fixed hypotheses is better, but which learning algorithm performs better on average. The comparison should account for variation caused by the choice of training sets and test examples.

A practical classroom procedure is:

  1. Choose the same target task and evaluation metric.
  2. Repeat training and evaluation using multiple independent or carefully designed data splits.
  3. Record the test error for each algorithm on each run.
  4. Compare average performance and variability, rather than relying on a single split.
  5. Use a suitable statistical comparison that respects whether the runs or test examples are paired.

C. BAYESIAN LEARNING

18. Introduction to Bayesian Learning

Bayesian learning applies probability theory to learning. It calculates probabilities for hypotheses and updates those probabilities when data is observed. It can combine prior knowledge with evidence and can combine predictions from multiple hypotheses.

Strengths

  • It combines prior knowledge and observed data.
  • It can represent uncertainty rather than immediately eliminating every imperfect hypothesis.
  • It can make probabilistic predictions.
  • It provides a principled benchmark for decision-making.

Practical difficulties

  • Prior and conditional probabilities may not be known and must be estimated.
  • Computing the posterior for a very large hypothesis space can be expensive.

19. Bayes’ Theorem

Let \(h\) be a hypothesis and \(D\) the observed data:

\[P(h\mid D)=\frac{P(D\mid h)P(h)}{P(D)}\]
TermMeaning
\(P(h)\)Prior probability of hypothesis h before observing D.
\(P(D\mid h)\)Likelihood: probability of observing D if h is true.
\(P(D)\)Evidence or marginal probability of D.
\(P(h\mid D)\)Posterior probability after observing D.

The posterior increases with a larger prior or likelihood, all else equal. The evidence normalizes the posterior probabilities so that they sum to one.

20. Medical Diagnosis – Bayes’ Theorem Numerical Example

Your slides use a medical test example. Let:

  • Prevalence: \(P(C)=0.008\) (0.8%).
  • Sensitivity: \(P(+\mid C)=0.98\) (98%).
  • Specificity: \(P(-\mid\neg C)=0.97\), so false-positive rate \(P(+\mid\neg C)=0.03\).

Question: If a patient receives a positive result, what is the probability that the patient actually has the disease?

\[P(C\mid +)=\frac{P(+\mid C)P(C)}{P(+\mid C)P(C)+P(+\mid\neg C)P(\neg C)}\]

Substitute:

\[P(C\mid +)=\frac{0.98(0.008)}{0.98(0.008)+0.03(0.992)}\]
\[=\frac{0.00784}{0.00784+0.02976}=\frac{0.00784}{0.03760}\]
Posterior probability ≈ 0.2085 = 20.85%. Despite a 98% sensitivity and 97% specificity, a positive test in this low-prevalence population gives a posterior probability of about 20.85% under the stated assumptions. This illustrates the base-rate effect.

21. MAP and Maximum Likelihood Hypotheses

A maximum a posteriori (MAP) hypothesis is a hypothesis with the highest posterior probability:

\[h_{MAP}=\arg\max_{h\in H}P(h\mid D)\]

Using Bayes’ theorem:

\[h_{MAP}=\arg\max_{h\in H}P(D\mid h)P(h)\]

A maximum likelihood (ML) hypothesis maximizes the likelihood:

\[h_{ML}=\arg\max_{h\in H}P(D\mid h)\]

If all hypotheses have equal prior probability, a MAP hypothesis is also an ML hypothesis.

22. Bayes Theorem and Concept Learning

Consider a finite hypothesis space \(H\), instance space \(X\), target concept \(c:X\to\{0,1\}\), and noise-free training data \(D\).

Under the assumptions in the slides—uniform prior over hypotheses, target concept contained in H, and noise-free labels—the likelihood is:

\[P(D\mid h)=\begin{cases}1,&h\text{ is consistent with }D\\0,&h\text{ is inconsistent with }D\end{cases}\]

Therefore inconsistent hypotheses receive posterior probability zero. Every consistent hypothesis receives equal posterior probability under a uniform prior:

\[P(h\mid D)=\begin{cases}\frac{1}{|VS_{H,D}|},&h\in VS_{H,D}\\0,&h\notin VS_{H,D}\end{cases}\]

Thus every hypothesis in the version space is a MAP hypothesis under these assumptions. A consistent learner returns a hypothesis with zero training error. The slides connect this interpretation to Find-S and Candidate-Elimination.

23. Maximum Likelihood and Least-Squared-Error Hypotheses

For a continuous-valued target, suppose each training target is corrupted by independent, zero-mean Gaussian noise:

\[d_i=f(x_i)+e_i,\qquad e_i\sim N(0,\sigma^2)\]

The likelihood of the observed data is maximized by the hypothesis that minimizes the sum of squared errors:

\[h_{ML}=\arg\min_{h\in H}\sum_{i=1}^{m}(d_i-h(x_i))^2\]

Numerical example – Least-squares error

Suppose actual values are \(d=[3,5,7]\), and a model predicts \(\hat d=[2,5,8]\).

24. Maximum Likelihood for Predicting Probabilities

Sometimes the target is probabilistic. For example, patients with the same recorded features may have different outcomes because not all relevant factors are observed. A model may predict \(p_i=P(d_i=1\mid x_i)\).

For independent binary observations, the likelihood is:

\[P(D\mid h)=\prod_{i=1}^{m}p_i^{d_i}(1-p_i)^{1-d_i}\]

Taking the logarithm gives the log-likelihood:

\[\log P(D\mid h)=\sum_i[d_i\log p_i+(1-d_i)\log(1-p_i)]\]

Maximizing this expression is equivalent to minimizing the negative log-likelihood, also called cross-entropy for binary outcomes:

\[L=-\sum_i[d_i\log p_i+(1-d_i)\log(1-p_i)]\]

The slides connect likelihood maximization for neural networks with gradient ascent and the backpropagation update rule. The important conceptual point is that squared error corresponds to a Gaussian-noise assumption, whereas cross-entropy is appropriate for probabilistic binary predictions.

25. Minimum Description Length (MDL) Principle

MDL is closely related to Occam’s Razor: choose the explanation that gives the shortest total description of the hypothesis and the data not explained by it.

\[h_{MDL}=\arg\min_h\big[L(h)+L(D\mid h)\big]\]

Here \(L(h)\) is the number of bits needed to encode the hypothesis, and \(L(D\mid h)\) is the number of bits needed to encode the data given the hypothesis.

A complex hypothesis may describe the training data closely but require many bits to describe. A simple hypothesis may be shorter but leave more residual errors to encode. MDL balances these two costs.

With the coding lengths \(L(h)=-\log_2P(h)\) and \(L(D\mid h)=-\log_2P(D\mid h)\), minimizing total description length is equivalent to maximizing the posterior probability, and therefore produces a MAP hypothesis.

26. Bayes Optimal Classifier

The MAP method selects the single most probable hypothesis. The Bayes optimal classifier instead combines predictions from all hypotheses, weighted by their posterior probabilities.

\[P(v\mid x,D)=\sum_{h\in H}P(v\mid x,h)P(h\mid D)\]

For deterministic hypotheses, each hypothesis votes for a class, weighted by its posterior probability.

Numerical example

Suppose three hypotheses have posterior probabilities 0.4, 0.3 and 0.3. For a new instance \(x\), \(h_1\) predicts Positive, while \(h_2\) and \(h_3\) predict Negative.

HypothesisPosterior probabilityPrediction
h10.4Positive
h20.3Negative
h30.3Negative

Weighted probability of Positive = 0.4. Weighted probability of Negative = 0.3 + 0.3 = 0.6. Therefore the Bayes optimal classification is Negative, even though the MAP hypothesis \(h_1\) predicts Positive.

27. Gibbs Algorithm

The Bayes optimal classifier can be computationally expensive because it combines predictions from every hypothesis. The Gibbs algorithm provides a simpler alternative:

  1. Calculate or obtain the posterior distribution over hypotheses.
  2. Randomly select one hypothesis according to that posterior distribution.
  3. Use the selected hypothesis to classify the new instance.

The slides state that, under the relevant assumptions, the expected misclassification error of Gibbs is at most twice that of the Bayes optimal classifier. The advantage is lower computational cost; the disadvantage is that an individual random draw may vary.

28. Naïve Bayes Classifier

Naïve Bayes applies Bayes’ theorem using a simplifying conditional-independence assumption: given the class, the attributes are treated as conditionally independent.

\[P(C\mid x_1,\ldots,x_n)\propto P(C)\prod_{i=1}^{n}P(x_i\mid C)\]

For classification, calculate this quantity for each class and choose the class with the larger posterior score. The proportionality is sufficient when comparing classes because the evidence \(P(x)\) is common to all classes.

Naïve Bayes steps

  1. Calculate prior class probabilities.
  2. Calculate conditional probabilities of each attribute value given each class.
  3. For a new instance, multiply the prior by the relevant conditional probabilities.
  4. Compare the class scores and select the largest.

Worked example – PlayTennis query

Query: Outlook = Sunny, Temperature = Cool, Humidity = High, Wind = Strong. Use the standard 14-example PlayTennis dataset: 9 Yes and 5 No.

29. Estimating Probabilities and the m-estimate

A simple estimate of a conditional probability is the observed fraction:

\[P(X=v\mid C)\approx\frac{n_c}{n}\]

When \(n\) is small, this estimate can be unreliable. If \(n_c=0\), the estimated probability becomes zero and can force the entire Naïve Bayes class score to zero. The slides introduce the m-estimate to combine observed frequency with a prior estimate:

\[P(X=v\mid C)\approx\frac{n_c+mp}{n+m}\]

Here \(n_c\) is the number of occurrences of the value among the \(n\) examples in class C, \(p\) is the prior probability estimate, and \(m\) is the equivalent sample size. If an attribute has \(k\) possible values and a uniform prior is used, \(p=1/k\).

Numerical example

Suppose among 5 No examples, Wind=Strong occurs 3 times. Use \(p=0.5\) and \(m=2\):

\[P(Strong\mid No)\approx\frac{3+2(0.5)}{5+2}=\frac47\approx0.571\]

Without smoothing, the estimate is \(3/5=0.60\). The m-estimate moves the estimate toward the prior value 0.5. If \(m=0\), it reduces to the observed fraction.

31. Bayesian Belief Networks

A Bayesian belief network represents a joint probability distribution over a set of variables using a directed acyclic graph (DAG). Nodes represent random variables; directed edges represent direct probabilistic dependencies. Each node is associated with a conditional probability table given its parent nodes.

Conditional independence

Variables X and Y are conditionally independent given Z when knowing Y provides no additional information about X once Z is known:

\[P(X\mid Y,Z)=P(X\mid Z)\]

Naïve Bayes uses a strong conditional-independence assumption: all attributes are conditionally independent of one another given the class. Bayesian networks allow more general dependency structures.

Example
For a simplified educational network, Disease may influence Symptoms and TestResult. Symptoms and TestResult may be related through the common parent Disease. A Bayesian network represents these relationships and supports probability queries when its conditional tables are specified.

32. EM Algorithm – Scope in the supplied slides

The Unit II contents slide lists the EM (Expectation-Maximization) algorithm under Bayesian Learning. However, the supplied PDF ends after introducing Bayesian belief networks and conditional independence; it does not provide a detailed EM explanation or worked example.

For syllabus awareness, EM is a general iterative method for estimating model parameters when data include hidden or latent variables or incomplete information. It alternates between:

  1. Expectation (E) step: estimate the expected values or responsibilities of hidden variables using current parameter estimates.
  2. Maximization (M) step: update parameters to maximize the expected complete-data log-likelihood.

Final teaching message
Decision trees explain how to construct interpretable classification rules. Evaluation theory explains how much confidence to place in a learned model’s measured performance. Bayesian learning explains how to combine prior beliefs and observed evidence probabilistically. Together, these topics address how to learn, how to evaluate, and how to reason under uncertainty.
