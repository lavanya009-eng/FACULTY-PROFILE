# NAAC-Compliant Faculty Website

Multi-page static website for NAAC accreditation, SSR, AQAR, and DVV compliance.

## Key Features
- Separate pages for each NAAC criterion
- Print-friendly layouts
- DOI-visible publications
- Evidence-based structure
- No dependencies

## Files
- index.html - Home & statistics
- about.html - Profile & experience
- research.html - Publications with DOI
- projects.html - Funded research
- patents.html - IPR
- programs.html - Workshops
- talks.html - Invited lectures
- students.html - PhD supervision
- contact.html - Contact info
- styles.css - Shared styles

## Quick Start
1. Upload all files to web server
2. Open index.html
3. No configuration needed

## NAAC Usage
- Print pages for SSR annexures
- Reference URLs in documentation
- Update annually for AQAR

## Print Settings
- Enable background graphics
- Use normal margins
- 100% scale
